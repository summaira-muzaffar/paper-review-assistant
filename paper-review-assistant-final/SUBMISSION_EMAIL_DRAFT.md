Thank you for the assessment tasks you sent. I chose the third task, the LLM based document and paper review auto generation tool, and I have completed it.

The tool is a web application. A user uploads a paper as a PDF, the system extracts the full text and splits it into sections and paragraphs, and a large language model then reviews each paragraph and produces structured feedback: the issues found, a severity for each, an explanation, and a concrete revision suggestion, together with the paragraph's strengths. As required, the tool has a software interface, and the user can set their own review prompt for each paragraph, so different paragraphs can be reviewed with different instructions. All results are combined into one final report with an overall summary, which can be downloaded as a DOCX file. The interface works in English and Chinese, and the review can be generated in either language, through an OpenAI compatible API such as DeepSeek.
